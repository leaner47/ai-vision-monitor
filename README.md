# AI 视觉智能监测模型

私有化部署的视觉监控系统：YOLO 实时目标检测 + 本地视觉大模型（Qwen3-VL）风险因果推理，全开源、全本地运行，Mac / Windows 双平台。

## 功能

- 网页 Dashboard：多摄像头自动探测与网格分屏、实时目标框选、勾选检查对象
- VLM 风险分析：推理画面中的安全隐患因果（明火→火灾风险、线缆乱放→漏电风险等），轮询多路画面
- 训练校准：网页上输入类别、拖入图片，自动划分训练/验证集并增量训练 YOLO 分类模型
- 一键启停：浏览器关闭后自动停止全部服务并释放内存
- 一键环境配置：拷到新电脑后自动重建环境（含 Ollama 离线安装）

## 快速开始

本仓库只含代码与文档。完整交付包（含 6GB VLM 模型库、YOLO 权重、Ollama 离线安装包）请从移动硬盘整体拷贝；或按下述方式重建：

1. 运行 `一键环境配置`（Mac: .app / Win: .bat）——自动建 venv 装依赖
2. 下载 VLM 模型：`OLLAMA_MODELS=./ollama ollama pull qwen3-vl:8b`
3. 日常启动：Mac 双击 `AI巡检.app`，Win 双击 `快速启动.bat`

详细文档见 `docs/`：使用说明、Windows 运行指南、VLM 风险分析指南、部署需求。
