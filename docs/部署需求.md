# 最小部署需求

## 一、只跑 YOLO 识别（车辆分类 / 隐患检测）

| 项目 | 要求 |
|---|---|
| 电脑 | 普通办公机：i5 级 CPU + 8GB 内存，**无需显卡** |
| 系统 | Windows 10/11（或 Mac/Linux，同一套代码） |
| 磁盘 | 约 8GB（Python 环境 6GB + 模型和数据） |
| 速度 | CPU 推理每张图 50~200ms，实时视频流可跑 |

嵌入其他程序时用 ONNX + onnxruntime，无需装 Python，运行时不到 200MB。

## 二、加 VLM 风险因果推理（Ollama + qwen3-vl）

| 配置 | 效果 |
|---|---|
| 16GB 内存办公机，无显卡 | 跑 8B 模型，每帧 30~60 秒，定时抽帧巡检（每分钟一帧）够用 |
| 8GB 内存机器 | 换 4B 小模型（`ollama pull qwen3-vl:4b`，约 3.5GB），精度略降 |
| RTX 3060 12GB 级显卡（约两千元，唯一可能的开销） | 每帧 2~5 秒，接近实时巡检 |
| M3 Pro 36GB MacBook | 全部功能可跑，可直接当分析服务器 |

VLM 模型文件约 6GB（8B）/ 3.5GB（4B），磁盘总占用按 20GB 预留。

## 三、摄像头

任选其一，零或极低成本：

- 电脑自带摄像头 / 几十元 USB 摄像头
- 手机（iPhone 连续互通，或 IP Webcam 类 App）
- 现有监控摄像头的 RTSP 流（`--source rtsp://用户:密码@IP/stream`）

## 四、最省钱的部署形态

一台现有 16GB 办公机装 Ollama + 本套脚本，接办公室现有监控的 RTSP 流，每分钟抽帧分析、发现风险自动存档告警——**零新增硬件**。多路摄像头或要求秒级响应时，再考虑加一张显卡。
