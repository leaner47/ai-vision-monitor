# 图片识别模型训练工具 — 使用说明

程序、数据、虚拟环境、模型权重全部位于 **AI视觉智能监测模型 文件夹**：

```
/Volumes/DB_004/AI视觉智能监测模型/yolo-pipeline/     ← 项目（脚本+数据集）
/Volumes/DB_004/AI视觉智能监测模型/models/                   ← 预训练权重 + 训练产出模型
```

本文件夹（Untitled/视觉模型）只存放文字说明，不放程序和模型。

## 快速上手

**1. 首次安装环境（只需一次）**

```bash
cd /Volumes/DB_004/AI视觉智能监测模型/yolo-pipeline
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python scripts/common.py   # 验证：应显示 mps 和模型目录
```

**2. 放图片**（车辆分类示例，每类 30 张以上）

放入 `datasets/classify/train/` 下的 `car/`、`motorcycle/`、`ebike/` 文件夹，每类分几张到 `val/` 对应文件夹。

**3. 训练**

```bash
python scripts/train_classify.py
```

**4. 测试**

```bash
python scripts/predict.py --model /Volumes/DB_004/AI视觉智能监测模型/models/classify_best.pt --source 测试图.jpg
```

之后每次使用：

```bash
cd /Volumes/DB_004/AI视觉智能监测模型/yolo-pipeline
source venv/bin/activate
```

隐患检测（需标注框）、Windows 部署、常见问题等详见项目内 `README.md`。
